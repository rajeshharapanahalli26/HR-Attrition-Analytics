# HR Analytics: Employee Attrition Insights and Predictive Modelling

**Author:** Rajesh Harapanahalli  
**Programme:**  Data Analytics with AI 
**Project type:** Internship Project  

> ⚠️ **IMPORTANT:** The dataset used in this project is **entirely fictional**. It was synthesised by IBM data scientists for illustrative purposes. It does **not** represent real IBM employees or real IBM HR decisions. All findings apply only to this fictional dataset.

---

## Project Overview

An end-to-end HR analytics project that:

1. Explores a fictional 1,470-employee dataset to identify patterns associated with recorded attrition
2. Trains and compares four binary classification models to predict attrition
3. Presents results through an interactive four-page Streamlit dashboard

The overall recorded attrition rate in the fictional dataset is **16.1%** (237 of 1,470 employees).

---

## Business Problem

Employee attrition carries significant costs: recruitment, onboarding, training, and lost productivity. This project demonstrates how data analytics and machine learning can be applied to explore workforce patterns and build a classification model to identify records associated with attrition.

---

## Project Objectives

1. Analyse attrition patterns across departments, job roles, and employee characteristics
2. Examine relationships between workplace factors and recorded attrition
3. Train and compare multiple classification models
4. Evaluate model performance using metrics appropriate for imbalanced data
5. Build an interactive Streamlit dashboard communicating findings to an HR audience

## Predictive Modelling Approach

| Item | Value |
|------|-------|
| Problem type | Binary classification |
| Target | Attrition (1=Yes/Left, 0=No/Stayed) |
| Split | 80/20 stratified (random_state=42) |

| Test rows | 294 |
| Pipeline | ColumnTransformer → StandardScaler + OneHotEncoder → Classifier |

## Evaluation Metrics

| Metric | Value (Logistic Regression, test set) |
|--------|--------------------------------------|
| Accuracy | 0.7551 |
| Precision | 0.3563 |
| Recall | 0.6596 |
| F1-score | 0.4627 |
| ROC-AUC | 0.8042 |

**Why recall is prioritised:** Missing an at-risk employee (False Negative) is operationally costlier than a false alarm (False Positive) in a voluntary retention context.

## Known Limitations

1. Fictional dataset — findings cannot be generalised
2. All findings are associations — no causal relationships are established
3. F1=0.46, Recall=0.66 are moderate — not high-confidence predictions
4. Class imbalance (5.2:1) — accuracy alone is a misleading metric
5. No hyperparameter tuning applied to models
6. Cross-sectional data — no temporal trends observable

---

## Ethical Considerations

These predictions must **NOT** be used to:
- Dismiss, demote, or disadvantage individual employees
- Automatically deny promotions or opportunities
- Make legally binding employment decisions

Appropriate uses (aggregate and supportive only):
- Identify workforce segments for voluntary wellbeing support
- Inform the design of voluntary retention programmes
- Support HR team resource allocation (with human review)

Any real-world deployment would require a full bias/fairness audit and compliance with applicable employment law and data protection regulations.
